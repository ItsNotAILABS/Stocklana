# Stocklana Experience Forge

## Product rules
- Patch the existing Stocklana project; never replace it with a parallel product.
- Desktop web is primary.
- Default user verbs: Buy · Convert · Play · Shop · Send · AI.
- Keep deep finance/proof/build tooling under advanced surfaces.
- CMESH is never a PreStock. It belongs to the Pons / Robinhood Chain platform-token lane.
- Keep the PreStocks allowlist strict.

## Visual rules
- Near-black obsidian background.
- Acid lime primary action; cyan and violet secondary glows.
- Premium glass panels, restrained bloom, large grotesk hero type.
- Hero must explain the product visually with motion, not generic stock art.
- Home composition: hero media → six actions → wallet → featured PreStocks → game → shop → AI budget → activity.
- PreStocks should feel like companies, not protocol objects.
- Games lead with stake, payoff, max loss, and YES/NO.
- AI leads with merchants, budget, per-purchase cap, and ask-me-above.
- CMESH gets a distinct blue/violet mesh identity and a solo tab.

## Build workflow
1. Inspect current repo.
2. Preserve backend/API/finance modules.
3. Patch HTML/CSS/JS directly.
4. Bind visual controls to real routes.
5. Verify CMESH does not enter PreStocks eligibility.
6. Never fabricate chain/provider receipts.
