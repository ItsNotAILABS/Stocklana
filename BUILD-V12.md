# Stocklana V12 — Real Web App Shell

V12 keeps the full Stocklana execution codebase and replaces the constrained mobile-first shell with a desktop-first browser workspace.

## Product surfaces
- Home command surface
- Invest / tokenized equities
- Markets / payoff games
- Money / MAQUE / cards / transfers
- Credit / internal funded pool + Kamino route
- Agent Commerce / guarded internet purchases
- Launch Exchange / Robinhood Chain Pons v2 + Solana adapters
- System / accounting / Token-2022 / ISO 20022 / Phantasma
- Activity and proof surfaces

## What did not change
The existing Python server, market engine, V2 accounting substrate, vaults, settlement engine, 100 Agent Vault model, MAQUE payment fabric, Jupiter/Kamino/Meteora/Pons adapters, Solana clients, test suite, proof artifacts, and PQ security remain in the same executable project.
